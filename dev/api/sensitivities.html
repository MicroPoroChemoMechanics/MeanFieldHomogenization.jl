API — Sensitivities ​

Public lenses and autodiff entry points provided by MeanFieldHomogenization.Schemes. ForwardDiff is a strong dependency of MeanFieldHomogenization — the four derivative / gradient / jacobian / sensitivity functions are available out of the box, and the built-in SelfConsistent Newton-Raphson solver (NewtonDefault) uses the same machinery internally.

Lenses ​

MeanFieldHomogenization.Core.AbstractParameter Type
julia
AbstractParameter

Supertype of parameter lenses. Concrete subtypes designate a single scalar input of a homogenization computation:

  • AmountParameter — volume fraction or crack density of a phase.

  • PropertyParameter — one coefficient of a property tensor (:C, :K, …) of a phase or a layer, in a symmetry class that contains the tensor (:k, :μ, :ℓ₁ with symmetry = (:TI, n), a Kelvin-Mandel component :Mij, …).

  • PropertyDirection — the abscissa of a property tensor along a fixed tensor, zero in the cell.

  • GeometryParameter — a scalar geometry field of a phase (semi-axis of an ellipsoid, radius of a layer, …).

  • DistributionShapeParameter — a scalar field of the PCW / Maxwell distribution shape.

  • ThicknessParameter — the thickness of one layer of a laminate.

  • InterfaceParameter — a compliance or surface modulus of one imperfect interface of a laminate.

  • NestedParameter — a lens reaching into a declaratively nested cell, so that a multiscale chain differentiates end to end.

get_param / set_param read and replace the designated scalar in a cell. See also the convenience constructors amount, property, geometry, shape_param, thickness, interface_param and nested.

MeanFieldHomogenization.Schemes.AmountParameter Type
julia
AmountParameter(phase::Symbol)

Lens on the amount (volume fraction or crack density) of phase phase. Prefer the helper amount.

MeanFieldHomogenization.Schemes.AbstractPropertyParameter Type
julia
AbstractPropertyParameter <: AbstractParameter

A lens on the tensor of a property (property of the member phase of a cell): one of its coefficients (PropertyParameter) or its abscissa along a direction (PropertyDirection). A cell reads and replaces the tensor; what the scalar is in that tensor is decided by the lens.

MeanFieldHomogenization.Schemes.PropertyParameter Type
julia
PropertyParameter(phase, property, selector, symmetry = nothing)

Lens on one coefficient of a property tensor (property of the phase phase, :C, :K, …), in a symmetry class that contains the tensor:

  • symmetry = nothing: the tensor's own class, selector one of its named coefficients (:k, :μ, :α, :β of an isotropic stiffness, :ℓ₁ … :ℓ₆ of a transversely isotropic one, :C1111 … of an orthotropic one, …), an index of get_data, or a Kelvin-Mandel component :Mij (:Mi at order 2) in the canonical basis;

  • symmetry = (:TI, n), (:ORTHO, frame), (:CUBIC, frame): a class that contains the tensor, the tensor being written in it first; n is the unit vector of the axis and frame an orthonormal basis. The orientation may be left out (symmetry = :TI) when the tensor carries it: a TensTI for :TI, a TensOrtho or a TensCubic for :ORTHO, a TensCubic for :CUBIC;

  • symmetry = :ANISO or (:ANISO, basis): the Kelvin-Mandel components in basis (the canonical one by default), selector = :Mij.

The other coefficients of the class stay fixed when this one is set, so that a derivative is the partial derivative in that class. Prefer the helper property; the names of every class are in the manual page Sensitivities.

MeanFieldHomogenization.Schemes.PropertyDirection Type
julia
PropertyDirection(phase, property, direction)

Lens on the abscissa t of a property tensor along a fixed tensor: setting it replaces the tensor of the phase by   , direction being , a tensor of the order and the dimension of the property. Its value in a cell is zero, and a derivative with respect to it is the derivative of the result along , whatever the symmetry classes of the two tensors. Prefer the helper property; second_moment is built on it.

MeanFieldHomogenization.Schemes.GeometryParameter Type
julia
GeometryParameter(phase, field, index = nothing)

Lens on a scalar geometry field of a phase. For an NTuple field (e.g. semi_axes), index selects one element of the tuple ; otherwise leave index = nothing.

Prefer the helper geometry.

MeanFieldHomogenization.Schemes.DistributionShapeParameter Type
julia
DistributionShapeParameter(field, index = nothing)

Lens on a scalar field of the (Maxwell / PCW) distribution shape. Prefer the helper shape_param.

MeanFieldHomogenization.Schemes.LayerParameter Type
julia
LayerParameter(phase, layer, selector)

Lens on one coefficient of the modulus of the layer layer of the layered sphere or cylinder of the phase phase: :k, :μ for an isotropic layer (:scalar for its conductivity); for a layer transversely isotropic about the radius (TensND.radial_ti(SphericalChart(), …)), a component in the local frame, :Crrrr, :Cθθθθ, :Cθθφφ (:Cθθzz on a cylinder), :Crrθθ, :Crθrθ, a Walpole coefficient :ℓ₁, :ℓ₂, :ℓ₃, :ℓ₅, :ℓ₆, or a conductivity :radial, :tangential. The other coefficients of the same family stay fixed. Prefer the helper layer_param.

MeanFieldHomogenization.Schemes.LayerDirection Type
julia
LayerDirection(phase, layer, direction)

Lens on the abscissa of the modulus of one layer of a layered sphere or cylinder along a fixed tensor, isotropic or transversely isotropic about the radius (TensND.radial_ti(SphericalChart(), …)): zero in the cell, as PropertyDirection is for the property of a phase. An isotropic layer moved along a radial field becomes one. Prefer the helper layer_param.

MeanFieldHomogenization.Schemes.get_coefficient Function
julia
get_coefficient(t, selector; symmetry = nothing)

The coefficient selector of the tensor t, in the symmetry class symmetry that contains it (its own class by default): get_coefficient(C, :k) is the bulk modulus of an isotropic stiffness, get_coefficient(C, :ℓ₁; symmetry = (:TI, n)) its first Walpole coefficient about n, get_coefficient(C, :M12) its Kelvin-Mandel component (1, 2). The selectors and the classes are those of property, listed in the manual page Sensitivities.

Examples

julia
julia> using MeanFieldHomogenization

julia> C = iso_stiffness(10.0, 4.0);

julia> get_coefficient(C, :k), get_coefficient(C, :α), get_coefficient(C, :μ)
(10.0, 30.0, 4.0)

julia> get_coefficient(C, :M44) ≈ 2 * 4.0      # the Kelvin-Mandel component of the shear
true
MeanFieldHomogenization.Schemes.set_coefficient Function
julia
set_coefficient(t, selector, v; symmetry = nothing)

The tensor of the class symmetry (the class of t by default) whose coefficient selector is v, its other coefficients being those of t. With a dual number v, a derivative with respect to that coefficient; the class must contain t.

Examples

julia
julia> using MeanFieldHomogenization, TensND

julia> C = set_coefficient(iso_stiffness(10.0, 4.0), :μ, 5.0);

julia> get_coefficient(C, :k), get_coefficient(C, :μ)
(10.0, 5.0)

Autodiff entry points ​

MeanFieldHomogenization.Schemes.derivative Function
julia
derivative(rve, scheme, param::AbstractParameter;
           output = :C, indexer = identity, kw...) -> Number | AbstractTens

Scalar derivative of homogenize(rve, scheme; property=output) with respect to the parameter selected by the lens param.

indexer is a function that extracts a scalar from the effective tensor (for example C -> get_data(C)[1] / 3 for the bulk modulus). Without an indexer, the derivative of the full tensor is returned — this is valid as long as ForwardDiff can propagate through the result (typically when the output is itself a structured object whose components ForwardDiff handles natively, via the _data Dual fields).

Extra kw... are passed to homogenize.

See also gradient, jacobian, sensitivity.

MeanFieldHomogenization.Schemes.gradient Function
julia
gradient(rve, scheme, params::AbstractVector{<:AbstractParameter};
         output = :C, indexer, kw...) -> Vector

Gradient of a scalar functional (extracted via indexer) of the effective tensor returned by homogenize(rve, scheme; property=output), with respect to the vector of lenses params.

Implementation: ForwardDiff.gradient, with its own chunk size or with the ForwardDiff.Chunk given as chunk.

MeanFieldHomogenization.Schemes.jacobian Function
julia
jacobian(rve, scheme, params::AbstractVector{<:AbstractParameter};
         output = :C, indexer = identity, kw...) -> Array

Jacobian (returned as a flat array length(output_flat) × length(params)) of homogenize(rve, scheme; property=output) with respect to the vector of lenses params.

indexer can be used to reduce the output to a sub-tensor before flattening. Without an indexer, the full effective tensor is flattened from its components in the canonical basis.

MeanFieldHomogenization.Schemes.sensitivity Function
julia
sensitivity(f, x₀; kind = :auto, kw...)

Generic ForwardDiff wrapper. f(x) is a user-supplied closure that builds or perturbs an RVE, runs homogenize, and returns a scalar (or a tensor).

kind:

  • :derivative — scalar x₀, scalar output; returns .

  • :gradient — vector x₀, scalar output; returns  .

  • :jacobian — vector x₀, tensor output; returns the flattened Jacobian.

  • :auto (default) — pick one of the above from the types of x₀ and f(x₀).

This entry point covers cases the AbstractParameter lenses cannot express (compound parametrizations, user-defined inclusion types without an exposed scalar field, etc.).
