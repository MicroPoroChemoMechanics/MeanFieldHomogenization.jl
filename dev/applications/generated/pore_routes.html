A concave pore through every route ​

The whole page as one script

Every block of this page, in order, is scripts/77_supersphere_pore_routes.jl. From a clone of the repository, julia --project=docs -e 'using Pkg; Pkg.instantiate()' once, then julia scripts/77_supersphere_pore_routes.jl, runs it end to end.

Before this page

Choosing an inclusion, which compares the routes on paper, and Concave pores: superspheres and superspheroids, which details the finite-element cell used here.

A superspherical pore has no closed form. This page computes its compliance contribution by the four routes the package offers for such a shape: a published table entered as a custom inclusion, a finite-element cell, a network trained on that cell, and the integral equation solved on a grid of Gaussians. The published values are those of Chen, Sevostianov, Giraud and Grgic. The sphere, where the answer is exact, measures the error of each route; the concave shapes show where the routes part.

julia
using MeanFieldHomogenization
using TensND
using LinearAlgebra
using JSON
using Printf
using Plots

A pore of volume in a matrix of compliance , under the remote stress , adds to the mean strain of a volume the term

which defines its compliance contribution tensor (Concentration and contribution tensors). A supersphere has the symmetry of the cube, so has three independent components in the axes of the pore: , and . All the values of this page are  , without dimension, for a matrix of Young modulus and Poisson ratio  .

const ν₀ = 0.3
const C₀ = iso_stiffness_E_nu(1.0, ν₀)                 ## E₀ = 1: the tensors below are E₀ ℍ
cubic(H) = (H[1, 1, 1, 1], H[1, 1, 2, 2], H[1, 2, 1, 2])
contribution(pore) = cubic(canonical_components(inverse_property_contribution(pore, 0 * C₀, C₀)))

Read in Table 3 of the Appendix, pp. 168-169 checked against the source

Transcribed from the published article (PDF), read on the page text with word positions; the page of the component H1133 compared with its image

Components of the compliance contribution tensor of a pore bounded by |x1|^(2p) + |x2|^(2p) + |x3/gamma|^(2p) = 1 (Eq. 1.1), with the normalization of Eq. (2.1): extra strain = (V*/V) H : stress, V* the volume of the pore. The values are dimensionless. The article does not state the factor in the text read; at p = 1 and gamma = 1 they equal E0 H of a spherical pore for a Poisson ratio of the matrix 0.3 to within 0.05 %, and the article gives nu0 = 0.30 for its Section 4. The components H1122 and H1133 are printed with a minus sign in the header, i.e. the tables give -H1122 and -H1133; they are stored here with their sign. The table of H1133 is printed with seven columns, gamma = 0.2 to 5.0: it has no column gamma = 0.1. The pore of this article has three separate exponents: it is axisymmetric for p = 1 only, and for gamma = 1 it is the supersphere.

A table of contribution tensors is the level C of the custom-inclusion interface: the two contribution tensors are supplied, and nothing else. The stiffness contribution follows from the compliance one by     . The published values are for   and scale as , which the callbacks check.

julia
function published_pore(p)
    H₁ = cubic_from_constants(published(p)..., CanonicalBasis{3, Float64}())        ## E₀ ℍ
    E_of(P₀) = first(E_nu(P₀))
    function check(P₀)
        isapprox(last(E_nu(P₀)), ν₀; atol = 1.0e-12) ||
            throw(ArgumentError("the published values hold for a Poisson ratio of $ν₀"))
        return nothing
    end
    return CustomInclusion(;
        inverse_property_contribution = (P₁, P₀; kw...) -> (check(P₀); H₁ / E_of(P₀)),
        property_contribution = (P₁, P₀; kw...) -> (check(P₀); -(P₀ ⊡ (H₁ / E_of(P₀)) ⊡ P₀)),
    )
end

Such a pore enters a cell like any other inclusion. Level C does not give the concentration tensor, so the schemes that need it (MoriTanaka, the self-consistent ones) refuse the phase; the dilute estimate, Maxwell, the scheme of Ponte Castañeda and Willis and the differential scheme accept it.

julia
function porous(pore, f)
    rve = RVE(; distribution_shape = Ellipsoid(1.0))        ## an isotropic distribution, read by Maxwell
    add_phase!(rve, :matrix, Ellipsoid(1.0), Dict(:C => C₀); fraction = :rest)
    add_phase!(rve, :pores, pore, Dict(:C => C₀); fraction = f, symmetrize = IsoSymmetrize())
    return rve
end

Route 2: a finite-element cell ​

FESupershapePore solves one pore in a finite cell with a corrected boundary condition (Finite-element inclusions). The documentation build does not mesh: the values below were computed once by scripts/fe/make_cell_figures.jl convergence, on one octant of a cell of radius , for three levels of subdivision of the surface of the pore.

julia
const fe = JSON.parsefile(joinpath(pkgdir(MeanFieldHomogenization), "docs", "src", "assets", "fe", "supersphere_convergence.json"))

fe_dofs(p, level) = only(r["dofs"] for r in fe["rows"] if r["p"] == p && r["level"] == level)

Route 4: a grid of Gaussians ​

GaussianInclusion solves the integral equation of the heterogeneity on a regular grid of n nodes per side, with no mesh (Heterogeneities of any shape). A pore is entered as a heterogeneity times softer than the matrix.

julia
const solved = Dict{Tuple{Float64, Int}, NTuple{3, Float64}}()        ## each grid is solved once
gaussian(p; n) = get!(solved, (p, n)) do
    cubic(canonical_components(inverse_property_contribution(GaussianInclusion(Supersphere(1.0, p); n), 1.0e-4 * C₀, C₀)))
end

Three observations.

  • For a convex pore the routes agree. From the sphere to   the cell is within 0.2 % of the published values and the network within 0.3 %. The grid of Gaussians is within 4 %.

  • A concave pore separates them. At   the finest cell is 2 % below the published value and still rising with the refinement, and the network trained on such cells is at the same distance; the grid of 16 nodes is 32 % below.

  • The published table is itself a computation. Its authors report, for the spheroid, an error below 1 % except at the two flattest shapes. It is the reference of this page because it is the finest of the four meshes, not because it is exact.

The grid of Gaussians, refined on the most concave pore, comes closer slowly: the arms of the pore are thinner than a few nodes, and the pore is empty, the stiffest contrast for this method.
