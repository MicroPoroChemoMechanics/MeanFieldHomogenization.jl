Elastic and conductive properties of porous and cracked materials ​

The whole page as one script

Every block of this page, in order, is scripts/110_cross_property_connections.jl. From a clone of the repository, julia --project=docs -e 'using Pkg; Pkg.instantiate()' once, then julia scripts/110_cross_property_connections.jl, runs it end to end.

Before this page

Cross-property connections, which says when a connection between the two properties is exact and what its approximate form drops, Extension to conductivity for the resistivity contribution, and Cracks and Conductivity for the syntax.

Pores and cracks lower both the stiffness and the conductivity of a solid. This page computes the two changes for one shape at a time, sets their ratio against the closed forms of Bristow and of Sevostianov and Kachanov, as the review of Sevostianov and Kachanov gives them, then uses the ratio on two sets of measurements reviewed in the same work: a closed-cell aluminum foam and plasma-sprayed zirconia coatings.

julia
contributions(pore, C₀, K₀) = (compliance_contribution(pore, 0 * C₀, C₀), resistivity_contribution(pore, 0 * K₀, K₀))
contributions(crack::EllipticCrack, C₀, K₀) = (compliance_contribution(crack, C₀), resistivity_contribution(crack, K₀))

function relative_changes(shape, E₀, ν₀, k₀)                        ## per unit weight, random orientations
    H, R = isotropify.(contributions(shape, iso_stiffness_young_poisson(E₀, ν₀), TensISO{3}(k₀)))
    return E₀ * canonical_components(H)[1, 1, 1, 1], k₀ * canonical_components(R)[1, 1]
end
connection(shape, ν₀) = (c = relative_changes(shape, one(ν₀), ν₀, one(ν₀)); c[1] / c[2])

The same numbers come out of one cell that carries both properties, :C and :K, homogenized twice by the scheme without interactions (DiluteDual), here at the density  :

julia
function cracked_cell(E₀, ν₀, k₀, ρ)
    C₀, K₀ = iso_stiffness_young_poisson(E₀, ν₀), TensISO{3}(k₀)
    rve = RVE()
    add_phase!(rve, :matrix, Ellipsoid(1.0), Dict(:C => C₀, :K => K₀); fraction = :rest)
    add_phase!(rve, :cracks, penny, Dict(:C => C₀, :K => K₀); density = ρ, symmetrize = IsoSymmetrize())
    return rve
end
young(C) = 1 / canonical_components(inv(C))[1, 1, 1, 1]
conductivity(K) = canonical_components(K)[1, 1]
cell = cracked_cell(1.0, 0.33, 1.0, 0.1)
E = young(homogenize(cell, DiluteDual(), :C))
k = conductivity(homogenize(cell, DiluteDual(), :K))
(ΔE = 1 / E - 1, Bristow = 0.1bristow_E(0.33), Δk = 1 / k - 1, closed_form = 0.1 * 8 / 9)

For spheroids of aspect ratio (the polar semi-axis over the equatorial one), oriented at random, the coefficient is computed over four decades of , from flat oblate pores to long needles, for two Poisson ratios. The flat end tends to Bristow's crack value, the dotted lines:

julia
γs = 10.0 .^ range(-2, 2; length = 49)
spheroid(γ) = Ellipsoid(1.0, 1.0, γ)
shape_curves = plot(;
    xscale = :log10, xlabel = "aspect ratio γ", ylabel = "ψ = [(E₀-E)/E] / [(k₀-k)/k]",
    legend = :topright, size = (620, 360), title = "Pores at random: connection coefficient", titlefontsize = 10
)
ψ_spheroids = Dict{Float64, Vector{Float64}}()
for (ν, color) in ((0.2, 1), (0.33, 2))
    ψ_spheroids[ν] = [connection(spheroid(γ), ν) for γ in γs]
    plot!(shape_curves, γs, ψ_spheroids[ν]; lw = 2, color, label = "ν₀ = $ν")
    hline!(shape_curves, [bristow_ψ(ν)]; color, ls = :dot, label = false)
    scatter!(shape_curves, [1.0], [sphere_ψ(ν)]; color, markersize = 4, label = false)
end

The two properties by the schemes ​

One cell carries the alloy with both properties and the pores, spheroids of aspect ratio 0.7 at random, with zero stiffness and zero conductivity. Each scheme estimates the two properties of the same cell (Cells and schemes):

julia
function foam_cell(p)
    C₀, K₀ = iso_stiffness_young_poisson(E₀, ν₀), TensISO{3}(k₀)
    rve = RVE()
    add_phase!(rve, :alloy, sphere, Dict(:C => C₀, :K => K₀); fraction = :rest)
    add_phase!(rve, :pores, spheroid(0.7), Dict(:C => 0 * C₀, :K => 0 * K₀); fraction = p, symmetrize = IsoSymmetrize())
    return rve
end

Plasma-sprayed zirconia coatings ​

Yttria-stabilized zirconia coatings (Sevostianov and Kachanov (2009), section 7.5; Kachanov and Sevostianov (2018), section 7.1) hold microcracks of two families, roughly parallel to the substrate plane and normal to it. function two_families(k₃)
    weight(H_h, H_v) = (4π / 3) * (H_h + 2.8 * H_v)
    s = (1 / k₃ - 1 / k₀z) / canonical_components(weight(R_h, R_v))[3, 3]
    S = inv(C₀z) + s * weight(H_h, H_v)
    return (E₁ = 1 / canonical_components(S)[1, 1, 1, 1], ρ_h = s, ρ_v = 2.8s)
end
