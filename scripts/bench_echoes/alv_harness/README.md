# `alv_harness/`: aging linear viscoelastic homogenization, Echoes side

Reference results of Echoes (C++, called from Python) for aging linear viscoelastic (ALV)
mean-field homogenization, to be compared with MeanFieldHomogenization.jl. This directory
holds the Echoes side only:

| File | Role |
|---|---|
| [`cases.py`](cases.py) | `CASES`, a list of dicts: time grid, closed-form kernels, fractions, shapes, angles, symmetrization, scheme |
| [`run_echoes.py`](run_echoes.py) | runs the cases and writes `results/<case>.json` |
| `results/` | one JSON per case (regenerated by `run_echoes.py`) |

## Rerun

From this directory, with the interpreter of the environment where `echoes` imports:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
systemd-run --user --scope -q -p MemoryMax=2000M -p MemorySwapMax=0 \
    python -I run_echoes.py                      # every case
python -I run_echoes.py b3_prolate_rot_MT        # one case (its sources first, if multiscale)
```

The whole set runs in a few seconds and stays below 200 MB.

The MeanFieldHomogenization side, from the package root, in an environment where the
package and `JSON` load:

```bash
julia --project=<env> scripts/bench_echoes/alv_harness/run_mfh.jl   # compares and times every case
```

`ALV_HARNESS_N=<N>` (on both sides) runs every case on a geometric grid of `N` instants over
the same span, into `results_n<N>/`: the timing at a realistic size.

## Contents of a result file

| Key | Content |
|---|---|
| `case` | the case dict, as in `cases.py` (rebuild everything from it) |
| `times` | the time grid t_0 < ... < t_{n-1} |
| `unitsize` | u = 6 (order 4) or 3 (order 2) |
| `effective` | the effective discretized relaxation operator, (n u) x (n u), row-major nested list |
| `phase_mats` | the discretized relaxation operator Echoes used for each phase |
| `discretization_check` | max relative gap between `phase_mats` and an independent re-implementation of the rule below (0 or 1e-16) |
| `max_abs_strict_upper_block` | max over the blocks above the diagonal (0: causal) |
| `wall_time_s` | minimum over 3 runs of the `homogenize_visco` call alone |
| `conventions` | the facts below, with their source lines |

The wall time covers `homogenize_visco` only: the RVE is rebuilt outside the timed region
for every run (a self-consistent RVE keeps its previous result as the next starting
point). It includes the discretization of the kernels, which Echoes performs inside that
call by calling the Python kernel at every pair of instants.

## Conventions, read in `echoes_cpp`

**Layout.** An operator on n instants is an (n u) x (n u) matrix of u x u blocks,
time-major: block (i, j) occupies rows u i .. u(i+1)-1 and columns u j .. u(j+1)-1
(`subarray`, `src/echoes/tensors/tensor_conversion.h:680-685`). It maps the stacked
strains (eps(t_0), eps(t_1), ...) to the stacked stresses.

**Components.** Kelvin-Mandel, order (11, 22, 33, sqrt2 e23, sqrt2 e31, sqrt2 e12)
(`tensor_conversion.h:295-299` for vectors, `422-445` for 4th-order tensors: sqrt2 on
normal-shear entries, 2 on shear-shear entries). Note the order 23, 31, 12. Not Voigt.

**Trapezoidal rule.** A kernel R(t, t') is discretized as the Stieltjes integral
sigma(t_i) = R(t_i, t_0) eps(t_0) + sum_k (R(t_i, t_k) + R(t_i, t_{k-1}))/2 (eps(t_k) - eps(t_{k-1})),
which gives the blocks (`src/echoes/viscoelasticity/visco_law.h:102-127`, scalar version
`src/echoes/visco_law.cpp:79-103`):

| Block | Value |
|---|---|
| (0, 0) | R(t_0, t_0) |
| (i, i), i > 0 | (R(t_i, t_{i-1}) + R(t_i, t_i)) / 2 |
| (i, 0), i > 0 | (R(t_i, t_0) - R(t_i, t_1)) / 2 |
| (i, j), 0 < j < i | (R(t_i, t_{j-1}) - R(t_i, t_{j+1})) / 2 |
| (i, j), j > i | 0 |

The kernel is never evaluated with t < t'. A constant (elastic) kernel gives the
block-diagonal matrix with C on the diagonal (same rule, and `build_elastic_mat`,
`visco_law.h:292-302`, for a phase given only an elastic `prop`).

**Creep laws.** A law declared `CREEP` is discretized by the same rule into a creep matrix,
which is then inverted numerically (`invert_array`, LAPACK) to give the relaxation matrix
the schemes use (`visco_law.cpp:22-31`, `src/echoes/microstructure/inclusion.h:350-363`).
The relaxation matrix is therefore the inverse of the discretized creep kernel, not the
discretization of the relaxation kernel.

**Angles.** Echoes (theta, phi, psi) with P = Rz(phi) Ry(theta) Rz(psi)
(`src/echoes/tensor_angles.cpp:71-81`): the columns of P are the local axes, local axis 3
is (sin theta cos phi, sin theta sin phi, cos theta). The Kelvin-Mandel image R6 of P
(`echoes.rot6`) maps local to global: C_global = R6 C_local R6^T; `run_echoes.py` builds
R6 itself (`mandel_rotation`) and it matches `echoes.rot6` to 1e-16. Rotating an ellipsoid
by these angles rotates the result exactly: b3 = R6 b1 R6^T and b4 = R6 b2 R6^T to 1e-15
(block-diagonal R6).

**Schemes** (`src/echoes/homogenization/homogenization_scheme.h`), with A_r the strain
concentration (I + P_0 (C_r - C_0))^{-1} (`inclusion_ellipsoid.h:206-222`), C_0 the
reference, f_r the fractions, {.} the orientation average:

* dilute: C_0 + sum_{r != matrix} f_r ({C_r A_r} - C_m {A_r}), C_0 = C_m (lines 1010-1038);
* Mori-Tanaka: (f_m C_m + sum f_r {C_r A_r}) (f_m I + sum f_r {A_r})^{-1}, C_0 = C_m
  (lines 864-904);
* self-consistent: the same expression with C_0 = the unknown and every phase, matrix
  included, through its A_r, by fixed point; stop when
  ||X_{k+1} - X_k||_F <= epsrel ||X_k||_F (`common_tools/nonlinear_solver.h:284-320`);
  start from the RVE's own stored operator if it has the right size, else the matrix's
  (`homogenization_selfconsistent.h:194-205`).

The orientation average is applied to A_r and to C_r A_r separately, block by block
(`homogenization_scheme.h:894-897`, `inclusion.h:824-832`), never to their product.

## Cases

Grid: 12 instants, geometric from 0.1 to 20. Aging factor g(t') = 1 - 0.5 exp(-t'),
kernels written out in the docstring of `cases.py`. ROT = (0.4, 0.9, 0.2).

| a1 / a2 | 4 | DIL / MT | aging Maxwell matrix, elastic spheres |

| a4 | 4 | MT | aging Maxwell matrix, aging Kelvin (CREEP) spheres |
| a5 | 4 | SC | three phases: Maxwell matrix, Maxwell spheres, Kelvin (CREEP) spheres |

| b7 | 4 | MT | prolate, isotropic orientation average |

| c1 | 4 | MT | spheres with a TI aging Maxwell law of axis ROT |
| c2 | 4 | MT | prolate rotated by ROT, TI law of the same axis |
| c3 | 4 | DIL | prolate rotated by ROT, TI law of another axis (1.1, 0.3, 0) |
| d1 / d2 | 2 | MT / SC | conduction, spheres (elastic / Kelvin CREEP inclusions) |

| d4 | 2 | DIL | conduction, oblate rotated by ROT, TI conductivity law of axis (1.1, 0.3, 0) |

`interface/python/py_echoes/py_microstructure/py_inclusion.h:75-99`).

## Limitations of Echoes that shaped the cases

* **A crack has a volume.** Echoes builds a crack as a flat ellipsoid of semi-axes
  (a, b, c), its compliance the limit c -> 0 (`eshelby4_builder_dim3_iso.h:200-252`), but
  takes the volume (4 pi/3) density eta c off the matrix fraction: an error proportional to
  c, measured 1.2e-5 at c = 1e-4 b on f3 and 1.2e-8 at 1e-7 b. The crack cases use
  c = 1e-12 b. Its crack density is N a^3 and its compliance is normalized by a: the same
  family has the density eta^2 times Echoes' in MeanFieldHomogenization (N a b^2), see the
  docstring of `cases.py`.

* **The reference medium is isotropic in ALV.** The ALV Hill tensor is always built by the
  isotropic builders (`src/echoes/eshelby/eshelby_builder_factory.h:110-121`), which take
  the isotropic projection of the reference operator, block by block
  (`eshelby4_builder_dim3_iso.h:164-193`, `eshelby2_builder_dim3_iso.h:101-125`). An
  anisotropic matrix (MT, DIL) or an anisotropic self-consistent iterate is silently
  replaced by its isotropic part in P_0. Hence: SC only where the result is isotropic
  (spheres, isotropic average), anisotropic laws and multiscale operators only as
  inclusions or as an isotropic matrix (e2, e3).
* **Symmetrization: ISO and TI only** (`src/echoes/tensors/tensor_symmetry.h:245-255`);
  any other symmetry is silently ignored. The TI axis takes (theta, phi) only.
* **A numpy array handed to Echoes is borrowed, not copied.** The numpy-to-blitz
  converter wraps the numpy buffer without copying it unless the array has a single
  reference (`interface/python/array_wrapper.h:159-167`), and `set_visco_mat` keeps that
  buffer by reference (`inclusion.h:277-280`). Measured: a temporary passed straight to
  `rve.set_visco_mat` or to `visco_prop` is read back changed once Python frees it, and
  mutating a live array mutates Echoes' operator. `run_echoes.py` keeps every array it
  hands over alive for the lifetime of the RVE. Without it, e1 gave a different result
  at each repetition.
