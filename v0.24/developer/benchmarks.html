Performance vs Echoes ​

Before this page

Performance notes, for the paths timed below, and Cross-validation against Echoes, for the accuracy of the same runs.

Every number on this page is read from a JSON file written by a script of the repository, and can be measured again by anyone with the commands of the last section. Both codes run on the same machine, one thread each, timed by BenchmarkTools' @belapsed (the minimum of the samples); Echoes is called through its Python API, from Python modules that also run on their own.   means that MeanFieldHomogenization is faster; a ratio below 1 is in bold. The gap is the largest relative difference between the two results, so that each ratio compares two computations of the same number.

The three-scale strength model: the same route, two stopping rules ​

The model of Quasi-brittle strength of cement paste and mortar computes a strength and its derivative with respect to the shear modulus of one family of hydrate needles. Both codes take the same route, described on the page of the model: the self-consistent foam is first converged with the needles averaged isotropically, whose Hill tensors are closed forms, and the 20 transversely isotropic families start from that estimate. They stop differently. Echoes takes a single step over the families and obtains the derivative there, with numerical Hill tensors to . MeanFieldHomogenization iterates the families to convergence, the derivative included through dual numbers, every Hill tensor to . The second row starts the families from the hydrate stiffness instead, the direct route kept to validate the first (Validating the angular discretization); both rows reach the same strength.

What the numbers say ​

  • Closed forms against Echoes' calls. On an isotropic medium both codes evaluate a closed form, and a Hill tensor costs tens of nanoseconds in Julia against tens of milliseconds through Echoes' Python API; the isotropic schemes inherit the factor.

  • Same algorithm, comparable speed. Residues against residues on a triclinic medium, and the anisotropic conductivity, differ by a factor 2 to 2.5. The one case where Echoes is faster, :decuhr on the rotated triclinic ellipsoid against Echoes' residues, is a cubature against residues.

  • The cubatures are the fastest general back-ends. :nestedquadgk agrees with NUMINT3D to and is 80 to 400 times faster.

  • Derivatives by automatic differentiation cost no more than closed forms. ForwardDiff through hill_tensor beats Echoes' closed-form derivative on the isotropic cases.

  • Aging viscoelasticity: 3.6 to 10 times faster on 11 instants, the self-consistent schemes in the cheapest algebra of the reference kernel.

Reproducing ​

The Julia scripts call the Echoes side through PythonCall, from Python modules next to them. Install Echoes in a Python environment of your choice, which must also have sympy (pip install sympy), activate it, then start Julia from the same shell: scripts/bench_echoes/echoes_python.jl, included by every script before PythonCall loads, takes the active python3 (or the interpreter named by ECHOES_PYTHON), checks that it imports echoes and sympy, and tells PythonCall to use it and CondaPkg to manage nothing. The explicit alternative is JULIA_CONDAPKG_BACKEND=Null and JULIA_PYTHONCALL_EXE=<path to that python>. CondaPkg then touches nothing, so the numpy version Echoes was built against (often numpy 1.x, numpy < 2) is kept; never let CondaPkg manage an environment where Echoes is installed, or pin that numpy in its CondaPkg.toml. Details in scripts/bench_echoes/README.md. From the root of the repository, alone on the machine:

bash
julia --project=scripts/bench_echoes scripts/bench_echoes/benchmark.jl
julia --project=scripts/bench_echoes scripts/bench_echoes/benchmark_schemes_speed.jl

They write scripts/bench_echoes/figures/benchmark_kernels.json and benchmark_schemes_speed.json, which this page reads. The Echoes side runs on its own as well, with the cases defined once in these modules:

bash
python3 -I scripts/bench_echoes/kernels_echoes.py
python3 -I scripts/bench_echoes/schemes_speed_echoes.py

with python3 the interpreter in which import echoes works.

Internal (Julia-only) regression benchmarking is separate: scripts/bench/ holds a gated suite with a committed baseline and a bitwise checksum gate, described in its own README.md.
