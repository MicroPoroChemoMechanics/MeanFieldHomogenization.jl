Before this page

Sensitivities, for the parameters and the symmetry classes their coefficients belong to.

A stiffness tensor has as many parametrizations as there are symmetry classes that contain it: an isotropic tensor is also transversely isotropic about any axis, orthotropic in any frame, and it always has its 21 Kelvin-Mandel components. Each parametrization gives derivatives of an effective property, and they are tied by the chain rule. This page computes the derivative of one effective component through each class and checks them against one another; it ends with a derivative that takes the tensor out of its own class.

julia
using MeanFieldHomogenization
using TensND
using ForwardDiff
using Printf

The cell ​

Spheres of an isotropic phase in an isotropic matrix, by the Mori-Tanaka scheme. The quantity differentiated is the component   of the effective stiffness.

julia
C_I = iso_stiffness(40.0, 30.0)                          # k, μ
function cell(C)
    rve = RVE()
    add_phase!(rve, :M, Ellipsoid(1.0), Dict(:C => iso_stiffness(10.0, 6.0)); fraction = :rest)
    add_phase!(rve, :I, Ellipsoid(1.0), Dict(:C => C); fraction = 0.3)
    return rve
end
f(C) = canonical_components(C)[3, 3, 3, 3]
∂(p) = derivative(cell(C_I), MoriTanaka(), p; indexer = f)

The chain rule ​

The derivative with respect to a coefficient of a class is a derivative along the tensor that this coefficient multiplies (Derivatives by automatic differentiation, section 6).

Let be a coefficient of any class that contains , and the Kelvin-Mandel matrix of the tensor in which varies, the other coefficients of its class held fixed. Since depends on through ,

where , for  , moves and together, which is what the parameter :Mij does. The 21 derivatives with respect to the Kelvin-Mandel components are computed once:

julia
D = Dict((i, j) => ∂(property(:I, :C, Symbol("M$i$j"))) for i in 1:6 for j in i:6)

and is the derivative of the tensor alone, without any homogenization, by ForwardDiff on the function that builds it:

julia
km(C) = mandel(C, TensND.CanonicalBasis{3, eltype(C)}())
by_chain_rule(tensor, p₀) = (dM = ForwardDiff.derivative(x -> km(tensor(x)), p₀); sum(D[(i, j)] * dM[i, j] for i in 1:6 for j in i:6))

The same tensor, transversely isotropic ​

About an axis , the isotropic tensor has five Walpole coefficients  . symmetry = (:TI, n) writes it in that class first:

julia
n = TensND.normalize([0.0, 1.0, 1.0])
T = first(TensND.project(C_I, :TI, n))
ℓ = TensND.get_data(T)
names = (:ℓ₁, :ℓ₂, :ℓ₃, :ℓ₅, :ℓ₆)
∂ℓ = [∂(property(:I, :C, s; symmetry = (:TI, n))) for s in names]
for (r, s) in enumerate(names)
    tensor(x) = TensND.rebuild(T, Base.setindex(ℓ, x, r))
    @printf "∂f/∂%s :  by name %.12f   by the chain rule %.12f\n" s ∂ℓ[r] by_chain_rule(tensor, ℓ[r])
end

A modulus of the isotropic class is a function of the Walpole coefficients, and the chain rule between the two classes gives a third time:

julia
dℓ_dk = ForwardDiff.derivative(k -> collect(TensND.get_data(first(TensND.project(iso_stiffness(k, 30.0), :TI, n)))), 40.0)
@printf "∂f/∂k = Σ ∂f/∂ℓᵣ ∂ℓᵣ/∂k = %.12f\n" sum(∂ℓ .* dℓ_dk)
∂f/∂k = Σ ∂f/∂ℓᵣ ∂ℓᵣ/∂k = 0.063905325444

Orthotropic components and Kelvin-Mandel components ​

In an orthotropic frame the coefficient is a component of the tensor, while   is its Kelvin-Mandel component: the derivatives with respect to them differ by that factor. Here the effective component differentiated is , which this shear moves.

julia
frame = TensND.CanonicalBasis{3, Float64}()
g(C) = canonical_components(C)[1, 3, 1, 3]
∂g(p) = derivative(cell(C_I), MoriTanaka(), p; indexer = g)
@printf "∂g/∂C₁₃₁₃ = %.12f   2 ∂g/∂M₅₅ = %.12f\n" ∂g(property(:I, :C, :C1313; symmetry = (:ORTHO, frame))) 2 * ∂g(property(:I, :C, :M55))
∂g/∂C₁₃₁₃ = 0.053460359254   2 ∂g/∂M₅₅ = 0.053460359254

A Hill tensor, by three routes ​

The same routes apply to any function of a tensor, here the Hill tensor of a prolate spheroid of axis in the isotropic matrix , differentiated with respect to the bulk modulus of the matrix. get_coefficient and set_coefficient read and set a coefficient of a tensor, in a class that contains it, as the parameters do in a cell.

julia
C₀ = iso_stiffness(10.0, 6.0)
spheroid = Ellipsoid(1.0, 1.0, 3.0)
P₃₃₃₃(C) = canonical_components(hill_tensor(spheroid, C))[3, 3, 3, 3]

Isotropic. is a coefficient of the class of :

julia
by_k = ForwardDiff.derivative(k -> P₃₃₃₃(set_coefficient(C₀, :k, k)), 10.0)
-0.00012999066451432103

Transversely isotropic. About , has five Walpole coefficients . The derivatives of with respect to them are taken with a matrix that is transversely isotropic, the other coefficients fixed; the chain rule through gives back the derivative with respect to :

julia
e₃ = [0.0, 0.0, 1.0]
ℓ₀ = get_coefficient.(Ref(C₀), names; symmetry = (:TI, e₃))
∂P_∂ℓ = [ForwardDiff.derivative(x -> P₃₃₃₃(set_coefficient(C₀, s, x; symmetry = (:TI, e₃))), ℓ₀[r]) for (r, s) in enumerate(names)]
∂ℓ_∂k = ForwardDiff.derivative(k -> [get_coefficient(iso_stiffness(k, 6.0), s; symmetry = (:TI, e₃)) for s in names], 10.0)
by_TI = sum(∂P_∂ℓ .* ∂ℓ_∂k)
-0.0001299906645143206

Anisotropic. Seen as a general anisotropic tensor, has 21 independent Kelvin-Mandel components. One call of ForwardDiff.gradient gives the 21 derivatives at once, the matrix being anisotropic as soon as one component moves; the chain rule through closes the loop:

julia
pairs = [(i, j) for i in 1:6 for j in i:6]
with_components(m) = foldl((C, ((i, j), x)) -> set_coefficient(C, Symbol("M$i$j"), x), zip(pairs, m); init = C₀)
∂P_∂M = ForwardDiff.gradient(m -> P₃₃₃₃(with_components(m)), [km(C₀)[i, j] for (i, j) in pairs])
∂M_∂k = ForwardDiff.derivative(k -> km(iso_stiffness(k, 6.0)), 10.0)
by_ANISO = sum(∂P_∂M[r] * ∂M_∂k[i, j] for (r, (i, j)) in enumerate(pairs))

(; by_k, by_TI, by_ANISO)
(by_k = -0.00012999066451432103, by_TI = -0.0001299906645143206, by_ANISO = -0.00012999066451426108)

The three numbers agree to rounding: each route is exact, and only the class in which the matrix is allowed to move differs.

Out of the isotropic class ​

Moving alone perturbs by a transversely isotropic tensor about : the inclusion is no longer isotropic, and neither is the derivative of the effective stiffness. jacobian gives all its components; their projections show the class it belongs to, the relative distance being for a class that contains it.

julia
J = jacobian(cell(C_I), MoriTanaka(), [property(:I, :C, :ℓ₅; symmetry = (:TI, n))])
∂C = Tens(reshape(J[:, 1], 3, 3, 3, 3))
@printf "relative distance of ∂Cʰᵒᵐ/∂ℓ₅ to the isotropic class %.2e, to TI(n) %.2e\n" last(TensND.project(∂C, :ISO)) last(TensND.project(∂C, :TI, n))
relative distance of ∂Cʰᵒᵐ/∂ℓ₅ to the isotropic class 7.75e-01, to TI(n) 7.17e-16

The derivative with respect to , by contrast, stays isotropic:

julia
J = jacobian(cell(C_I), MoriTanaka(), [property(:I, :C, :k)])
@printf "relative distance of ∂Cʰᵒᵐ/∂k to the isotropic class %.2e\n" last(TensND.project(Tens(reshape(J[:, 1], 3, 3, 3, 3)), :ISO))
relative distance of ∂Cʰᵒᵐ/∂k to the isotropic class 0.00e+00

This is the situation of the strength criterion of Quasi-brittle strength of cement paste and mortar, where the modulus of the hydrate needles of a single orientation is perturbed.
