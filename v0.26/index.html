What it does ​

Given a reference medium and an inclusion shape, MeanFieldHomogenization builds the Hill polarization tensor (Eshelby's result), derives the concentration tensor for each phase, and assembles a homogenization scheme — dilute, Mori–Tanaka, self-consistent, differential, PCW, or the classical bounds — into an effective stiffness or conductivity.

That chain is the whole library. The reading path follows it: first the problem of a single heterogeneity, an ellipsoid, a crack or a layered pattern; then the schemes that assemble those solutions, one family per page, from the bounds to the N-body schemes that resolve the interaction inclusion by inclusion; and finally the chain generalized in one direction at a time, a different physics for transport and a different time dependence for viscoelasticity.

Lineage: Echoes ​

MeanFieldHomogenization is the Julia successor of Echoes (Barthélémy, 2026), the mean-field homogenization library written in C++ with a Python interface by the same author at Cerema, documented in its own manual. The Eshelby and Hill machinery, the crack tensors, the -layer sphere, the schemes and the aging viscoelastic approach were ported from it, with the methods of the articles it implements: the compliance and the Hill polarization tensor of a crack in an anisotropic matrix (Barthélémy, 2009), the Hill polarization tensor of an ellipsoid and of a crack in an anisotropic conductor (Barthélémy, 2009), and the Eshelby problem and the schemes of aging linear viscoelasticity (Barthélémy et al., 2016; Barthélémy et al., 2019), discretized in time as proposed by Sanahuja (2013).

Echoes remains the reference of the port: the same problems are run by both libraries in Cross-validation, and their timings are compared in Performance vs Echoes. The port extends it in six directions:

  • numbers of any type: every computation accepts ForwardDiff dual numbers, so that the derivative of an effective property with respect to any parameter of the model (a fraction, an aspect ratio, a modulus at any scale, a time of a law) comes out of the same call, and symbolic numbers (Symbolics, SymPy), which give closed forms where the algorithm has no branch on a value;

  • closed forms: the Hill tensor of a spheroid coaxial with a transversely isotropic matrix, derived by transformation (Barthélémy, 2020), the opening displacement tensor of an elliptic crack in a matrix transversely isotropic about its normal (Barthélémy et al., 2021), and the displacement and stress intensity factors of elliptic and ribbon cracks (Barthélémy, 2026);

  • morphologies: confocal -layer spheroids with imperfect interfaces (Barthélémy and Bignonnet, 2020), periodic laminates, and inclusions whose response comes from a finite-element solution or a trained network;

  • interactions: the cluster model and the equivalent inclusion method, which act on the positions of the inclusions instead of a one-site average;

  • time: beside the aging approach, the non-aging approach in the Laplace–Carson domain, with numerical inversion and a catalog of rheological models;

  • use: homogenization as a constitutive law called by a finite-element code, the graphical interface MFH Studio, and echoes2mfh, which translates an Echoes script.

From Echoes to MeanFieldHomogenization gives the correspondence between the two libraries, class by class.

A first calculation ​

A porous solid, and every scheme the package ships, against the bounds that frame them. The void is given a small but non-zero stiffness, which is what lets the self-consistent branch stay on the physical solution:

julia
using MeanFieldHomogenization, TensND, Plots
gr()  # headless backend; GKSwstype is set to "100" in make.jl

C_solid = iso_stiffness(90.0, 30.0)     # GPa
C_void  = iso_stiffness(0.01, 0.005)

function bulk(f, scheme)
    r = RVE()
    add_phase!(r, :M, Ellipsoid(1.0), Dict(:C => C_solid); fraction = :rest)
    f > 0 && add_phase!(r, :V, Ellipsoid(1.0), Dict(:C => C_void); fraction = f)
    return first(k_mu(homogenize(r, scheme, :C)))
end

fs = range(0.0, 0.5; length = 61)
schemes = ("Voigt" => Voigt(),
           "Reuss" => Reuss(),
           "Mori-Tanaka" => MoriTanaka(),
           "Dilute (dual)" => DiluteDual(),
           "Self-consistent" => AsymmetricSelfConsistent(; abstol = 1.0e-10,
                                                           maxiters = 200,
                                                           select_best = true),
           "Differential" => DifferentialScheme(; nsteps = 100))

plt = plot(; xlabel = "porosity f", ylabel = "effective bulk modulus k [GPa]",
             legend = :topright, framestyle = :box, size = (760, 470))
for (name, s) in schemes
    plot!(plt, fs, [bulk(f, s) for f in fs]; label = name, lw = 2)
end
plt

Voigt and Reuss bracket the others; the three estimates between them differ by how much of the load each void is assumed to see. Porous materials works through why the standard self-consistent scheme fails on this problem and what replaces it, and Getting started takes a single estimate more slowly, defining each object on the way.

Reading paths ​

The documentation is organized by the question each chapter answers. Theory explains why an estimate is the right one, the Manual describes how each kind of object is written, the Tutorials drive a calculation from start to finish, and the Applications build complete models of real materials. Three entry points follow from it, depending on what the reader already knows.

New to mean-field homogenization. The chapter Theory is written for this reader and is best read in the order it states, from The Eshelby inclusion problem to Homogenization schemes, which together contain the whole chain that the rest generalizes. The tutorial A first homogenization then puts it to work.

Knowing what is to be computed. Getting started and Schemes and RVEs are enough to write a first model; the Manual then has one page per morphology, from Ellipsoidal inclusions to Neural-surrogate inclusions, and the Applications, from Multiscale elasticity of a hydrating cement paste onwards, show complete models.

Coming from Echoes. The correspondence between the two libraries, class by class, is in From Echoes to MeanFieldHomogenization, and echoes2mfh translates an existing script.

The symbols. Every symbol of the formulas is listed in the Nomenclature, with its meaning and its unit. Hovering an equation on any page shows the symbols it holds, with their meaning on that page.
