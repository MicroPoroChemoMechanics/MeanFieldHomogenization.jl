Symbolic viscoelasticity: closed forms, derived

The rheology catalog is generic in its scalar type, exactly as the tensor algebra is. Two consequences, independent of one another:

  • every model accepts symbolic parameters — SymPy Sym or Symbolics Num — and returns its Laplace-Carson transform as an exact expression;
  • with SymPy loaded, inverse_carson accepts a symbolic time and hands the inversion to SymPy, returning R(t) or J(t) in closed form instead of a number.

Together they let the closed forms be derived rather than transcribed — which is how the Burgers relaxation function, this package's sharpest numerical oracle, is checked below.

Terser script: scripts/66_symbolic_viscoelasticity.jl.

1. Symbolic parameters

using MeanFieldHomogenization
using TensND
using Symbolics

Symbolics.@variables E∞ E₁ τ₁ p t

m = zener_maxwell(E∞, E₁, τ₁)
Symbolics.simplify(carson_relaxation(m, p))

\[ \begin{equation} \frac{\mathtt{E{_1}} ~ p ~ \mathtt{\tau{_1}} + \mathtt{E\infty} ~ \left( 1 + p ~ \mathtt{\tau{_1}} \right)}{1 + p ~ \mathtt{\tau{_1}}} \end{equation} \]

The closed-form time function comes out symbolic too:

relaxation(m, t)

\[ \begin{equation} \mathtt{E\infty} + \mathtt{E{_1}} ~ e^{\frac{ - t}{\mathtt{\tau{_1}}}} \end{equation} \]

and the reciprocity identity — the definition of the creep transform — holds as an identity rather than to a tolerance:

Symbolics.simplify(carson_creep(m, p) * carson_relaxation(m, p) - 1)

\[ \begin{equation} 0 \end{equation} \]

Why this needed a change

The constructors validate their arguments — 0 < k < h < 1, τ > 0, and so on. A symbolic τ makes 0 < τ an expression, not a Bool, and using it in a boolean context throws. Symbolics.Num <: Real is famously not the predicate that separates the two: ForwardDiff.Dual is also <: Real and does compare to a Bool.

Every validation is therefore guarded by MeanFieldHomogenization.Elliptic.is_hard_numeric, so a symbolic model is simply not validated. That is the same guard the elliptic integrals have used since the confusion first bit.

The fractional and bituminous models, whose constructors carry the tightest validations, build symbolically as well, and the lift to a fourth-order tensor keeps everything symbolic:

The one thing a symbolic spectrum cannot do

maxwell_to_kelvin locates its roots by bisection between consecutive poles. That needs a real ordering of the relaxation times and a real sign test, neither of which a symbolic τ provides — so it refuses, with the reason, rather than failing later inside the bracketing:

try
    maxwell_to_kelvin(m)
catch e
    println(first(split(sprint(showerror, e), " The transform")))
end
ArgumentError: maxwell_to_kelvin: the conversion locates its roots by bisection between consecutive relaxation times, which needs a numeric spectrum — the times here are symbolic.

The transform itself is unaffected: carson_creep falls back on the exact J* = 1/R*, which is symbolic. Only the change of representation — and the closed-form time function that depends on it — needs numbers.

2. Symbolic Laplace-Carson inversion

With SymPy loaded, asking for the value at a symbolic time means something different from asking at a numeric one: not the value there but the function.

using SymPy

SymPy.@syms ts::positive τ::positive Einf::positive E1::positive

z = zener_maxwell(Einf, E1, τ)
inverse_carson(p -> carson_relaxation(z, p), ts)

\[E_{1} e^{- \frac{ts}{τ}} + Einf\]

It agrees with the closed form the model already carries — which is a check on both:

SymPy.simplify(inverse_carson(p -> carson_relaxation(z, p), ts) - relaxation(z, ts))

\[0\]

The creep function of the same standard solid, recovered from R*(p) alone:

SymPy.simplify(inverse_carson(p -> carson_creep(z, p), ts))

\[\frac{\left(- E_{1} + \left(E_{1} + Einf\right) e^{\frac{Einf ts}{τ \left(E_{1} + Einf\right)}}\right) e^{- \frac{Einf ts}{τ \left(E_{1} + Einf\right)}}}{Einf \left(E_{1} + Einf\right)}\]

Burgers: the oracle, derived

The relaxation function of the Burgers model is the cosh/sinh expression that had to be produced in a computer-algebra system to serve as the numerical oracle in test/Viscoelasticity/test_prony.jl. Here it is derived from the transform in one line:

SymPy.@syms ks::positive ηs::positive kp::positive ηp::positive

b = burgers(ks, ηs, kp, ηp)
inverse_carson(p -> carson_relaxation(b, p), ts)

\[\frac{ks \left(\left(kp ηs - ks ηp - ks ηs\right) \sin{\left(\frac{ts \sqrt{- kp^{2} ηs^{2} + 2 kp ks ηp ηs - 2 kp ks ηs^{2} - ks^{2} ηp^{2} - 2 ks^{2} ηp ηs - ks^{2} ηs^{2}}}{2 ηp ηs} \right)} + \sqrt{- kp^{2} ηs^{2} + 2 kp ks ηp ηs - 2 kp ks ηs^{2} - ks^{2} ηp^{2} - 2 ks^{2} ηp ηs - ks^{2} ηs^{2}} \cos{\left(\frac{ts \sqrt{- kp^{2} ηs^{2} + 2 kp ks ηp ηs - 2 kp ks ηs^{2} - ks^{2} ηp^{2} - 2 ks^{2} ηp ηs - ks^{2} ηs^{2}}}{2 ηp ηs} \right)}\right) e^{- \frac{ts \left(kp ηs + ks ηp + ks ηs\right)}{2 ηp ηs}}}{\sqrt{- kp^{2} ηs^{2} + 2 kp ks ηp ηs - 2 kp ks ηs^{2} - ks^{2} ηp^{2} - 2 ks^{2} ηp ηs - ks^{2} ηs^{2}}}\]

and the creep function, which carries the term linear in t that makes Burgers a fluid:

SymPy.simplify(inverse_carson(p -> carson_creep(b, p), ts) - creep(b, ts))

\[0\]

Name clash with Symbolics.jl

Symbolics exports its own inverse_laplace — a five-argument transform for solving ODEs — so once both packages are using-ed the bare name is ambiguous and must be qualified, MeanFieldHomogenization.inverse_laplace(F, t). inverse_carson, the one to use for anything in the catalog, is not affected.

3. How far the symbolic route reaches

This is worth stating precisely, because the boundary is not where one would guess.

A rational exponent inverts exactly.

SymPy.@syms V::positive
sb = ScottBlair(V, Sym(2) // 5)
(inverse_carson(q -> carson_creep(sb, q), ts), creep(sb, ts))
(5*ts^(2/5)/(2*V*gamma(2/5)), ts^(2/5)/(V*gamma(7/5)))

Those two are the same number written two ways — 5/(2Γ(2/5)) = 1/Γ(7/5).

The Cole-Cole model at α = 1/2 has a genuine closed form, since $E_{1/2}(-x) = e^{x^2}\operatorname{erfc}(x)$, and SymPy finds it:

SymPy.@syms E0::positive
inverse_carson(q -> carson_relaxation(FractionalZener(Einf, E0, τ, Sym(1) // 2), q), ts)

\[Einf + \left(E_{0} - Einf\right) e^{\frac{ts}{τ}} \operatorname{erfc}{\left(\frac{\sqrt{ts}}{\sqrt{τ}} \right)}\]

A symbolic exponent is where it stops — and it stops badly. SymPy returns nan rather than an unevaluated transform, which would propagate silently through every later substitution, so the extension warns:

SymPy.@syms α::positive
inverse_carson(q -> carson_creep(ScottBlair(V, α), q), ts)

\[\text{NaN}\]

A sum of several fractional powers — HuetSayegh, Model2S2P1D — is left unevaluated, which is at least honest, and is also warned about.

None of this is a gap in the package: those inverses are Mittag-Leffler functions or worse. It is precisely why inverse_carson with a numeric time and one of the four quadratures exists — FixedTalbot(24) inverts every one of these transforms to about 1e-12, as the inversion tutorial measures.

4. The two routes, on the same model

The symbolic and numerical inversions are entirely disjoint implementations, so their agreement is a real cross-check:

R_t = inverse_carson(p -> carson_relaxation(z, p), ts)
zn = zener_maxwell(2.0, 3.0, 1.5)

[
    (
        tv,
        Float64(R_t.subs(Dict(Einf => 2, E1 => 3, τ => Sym(3) // 2, ts => Sym(tv)))),
        inverse_carson(p -> carson_relaxation(zn, p), tv),
    ) for tv in (0.2, 1.0, 5.0)
]
3-element Vector{Tuple{Float64, Float64, Float64}}:
 (0.2, 4.625519957128843, 4.625519957131864)
 (1.0, 3.540251357097776, 3.540251357100552)
 (5.0, 2.107021980041757, 2.1070219800442387)
