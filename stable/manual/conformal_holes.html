Conformal holes ​

Before this page

Holes given by a conformal map, where the tensors returned below are derived, and Cylindrical inclusions, of which this page is the extension to sections that are not ellipses.

A ConformalHole is an infinite cylindrical cavity whose cross-section is given by a conformal map with a finite number of terms: a prismatic pore with rounded corners, a star-shaped channel, a slot. It is a cavity in elasticity and an insulator in conduction, in a matrix that is isotropic or transversely isotropic about the axis of the cavity. Its field is not uniform and it has no Hill tensor; its concentration tensors are exact.

julia
using MeanFieldHomogenization
using TensND
using LinearAlgebra
using Plots
# rounded for display, without negative zeros
tidy(M; digits = 3) = round.(Matrix(M); digits) .+ 0.0

Declaring a hole ​

The contour of the section is the image of the unit circle by

and the hole is declared by the coefficients , all of them or the nonzero ones as pairs degree => coefficient. The size is not given: the tensors are per unit volume of the cavity.

julia
ellipse = ConformalHole((0.5,))                    # m₁ = 0.5: semi-axes 1.5 R and 0.5 R
triangle = ConformalHole(2 => 0.25)                # m₂ = 0.25: three rounded corners
square = ConformalHole(polygon_map(4, 3)...)       # the first three terms of the map of a square
ConformalHole{Float64} (11 coefficient(s) of the map)

polygon_map returns the terms of the map of a regular polygon; the more terms, the sharper the corners. The coefficients must satisfy   , which makes the map one-to-one (Holes given by a conformal map, section 2); a complex coefficient turns the corresponding lobe.

julia
contour(hole) = [ζ + sum(m * ζ^(-k) for (k, m) in pairs(hole.coefficients)) for ζ in cis.(range(0, 2π; length = 361))]
holes = ["m₁ = 0.5" => ellipse, "m₂ = 0.25" => triangle, "square, 3 terms" => square,
    "pentagon, 20 terms" => ConformalHole(polygon_map(5, 20)...), "m₃ = 0.3, m₁ = 0.1i" => ConformalHole(1 => 0.1im, 3 => 0.3)]
plot([plot(real.(contour(h)), imag.(contour(h)); aspect_ratio = 1, fill = (0, 0.35, :orange), color = :black,
        legend = false, axis = false, grid = false, title = name, titlefontsize = 8) for (name, h) in holes]...;
    layout = (1, 5), size = (860, 200))

As for a Cylinder, the axis of the cavity is the first vector of the basis and the section lies in the plane of the two others, with    . The basis is given by the ZYZ euler_angles, or by basis:

julia
tilted = ConformalHole(polygon_map(3, 4)...; euler_angles = (0.0, π / 3, 0.0))

Its concentration tensors ​

In elasticity the strain concentration tensor is the mean strain of the cavity, defined from the displacement of its surface, per unit remote strain:

julia
C₀ = iso_stiffness(20.0, 12.0)             # bulk and shear moduli of the matrix
void = 0 * C₀                              # the property of the cavity, which is not read
A = gradient_gradient_concentration(square, void, C₀)
tidy(TensND.mandel(A))

In conduction the hole is an insulator, and its gradient concentration tensor depends on the first coefficient of the map and on the area of the section only:

julia
K₀ = TensISO{3}(2.0)
tidy(canonical_components(gradient_gradient_concentration(square, 0 * K₀, K₀)))
3×3 Matrix{Float64}:
 1.0  0.0    0.0
 0.0  2.188  0.0
 0.0  0.0    2.188

For the ellipse both are those of the elliptic Cylinder, obtained from its Hill tensor:

julia
norm(canonical_components(gradient_gradient_concentration(ellipse, void, C₀)) -
    canonical_components(gradient_gradient_concentration(Cylinder(1.5, 0.5), void, C₀)))
6.030545546184856e-15

In a scheme ​

The hole is added to a cell as any inclusion. Here aligned prismatic pores of square section, at a porosity of 10 %:

julia
rve = RVE()
add_phase!(rve, :matrix, Ellipsoid(1.0), Dict(:C => C₀); fraction = :rest)
add_phase!(rve, :pores, square, Dict(:C => void); fraction = 0.1)
C = homogenize(rve, MoriTanaka(), :C)
tidy(TensND.mandel(C))

The effective stiffness has the symmetry of the square about the axis of the pores.

The self-consistent and the differential schemes solve the hole in their own estimate. The hole accepts it when it is isotropic in the plane of the section, that is transversely isotropic about the axis of the pores (Holes given by a conformal map, section 7): for sections with an axis of symmetry of order 3, or of order 5 and more, and for any section oriented at random in the plane with symmetrize = TISymmetrize(axis). Triangular pores, then square ones turned at random about :

julia
function porous(hole; kw...)
    rve = RVE()
    add_phase!(rve, :matrix, Cylinder(1.0, 1.0), Dict(:C => C₀); fraction = :rest)
    add_phase!(rve, :pores, hole, Dict(:C => void); fraction = 0.1, kw...)
    return rve
end
C_triangles = homogenize(porous(ConformalHole(polygon_map(3, 20)...)), SelfConsistent(), :C)
C_squares = homogenize(porous(square; symmetrize = TISymmetrize((1.0, 0.0, 0.0))), SelfConsistent(), :C)

The matrix is here a phase of circular section, Cylinder(1.0, 1.0), so that the medium is invariant along the axis. Pores oriented at random in space are obtained with symmetrize = IsoSymmetrize().

In a cell of the plane ​

When the moduli of the plane are what is wanted, the hole is placed in a two-dimensional cell, whose properties are tensors of the plane (Plane problems): it is then its section, and its tensors are those of the plane. A plate with square holes, in plane stress:

julia
c = plane_stress_stiffness(C₀)             # the stiffness of the plate
plate = RVE()
add_phase!(plate, :matrix, Ellipsoid(1.0; dim = 2), Dict(:C => c); fraction = :rest)
add_phase!(plate, :holes, square, Dict(:C => 0 * c); fraction = 0.1)
tidy(TensND.mandel(homogenize(plate, MoriTanaka(), :C)))
3×3 Matrix{Float64}:
 22.886   6.61    0.0
  6.61   22.886   0.0
  0.0     0.0    18.032

Derivatives ​

The coefficients of the map and the moduli of the matrix are differentiated through the solution:

julia
using ForwardDiff
modulus(m) = canonical_components(homogenize(
    (r = RVE(); add_phase!(r, :matrix, Ellipsoid(1.0), Dict(:C => C₀); fraction = :rest);
        add_phase!(r, :pores, ConformalHole(3 => m), Dict(:C => void); fraction = 0.1); r),
    MoriTanaka(), :C))[2, 2, 2, 2]
ForwardDiff.derivative(modulus, 0.1)
-9.716237102608774

What is not covered ​

  • a reference medium that is anisotropic in the plane of the section, refused with a message;

  • a section that conducts or carries stress: the hole is empty;

  • a corner, which a finite map rounds: the tensors converge with the number of terms (Prismatic pores with corners);

  • a section given by a function or by pixels rather than by a map: the grid of Gaussians treats it in three dimensions (Heterogeneities of any shape).
