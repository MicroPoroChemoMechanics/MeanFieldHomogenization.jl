Layered cylinder: the transfer relations, symbolically, for the loading modes of the cylinder, and the theory pages The radial problem and Layered cylinder: layers transversely isotropic about the radius, which state the results derived here.

A layer of a LayeredCylinder may be transversely isotropic about the radial direction of the section, with moduli that depend on the radius. Each loading mode of the cylinder is then a system of the first order     on the state that an interface transmits. This page derives the matrices with TensND's differential operators in cylindrical coordinates, compares them with those of the package, and solves a layer graded as a power of the radius in closed form.

julia
using MeanFieldHomogenization
using TensND
using SymPyPythonCall
using LinearAlgebra

julia
# =============================================================================
#  radial_first_order.jl — a radial problem as a system of the first order,
#  symbolically (SymPyPythonCall).
#
#  A loading mode of a sphere or of a cylinder has a few radial functions as
#  unknowns. Its state Y gathers them and r times the radial functions of the
#  traction. `first_order_rhs` writes r dY/dr as expressions linear in symbols
#  y₁, y₂, … standing for the entries of Y: the constitutive law gives the
#  first derivatives of the unknowns from the tractions, the equilibrium
#  equations give their second derivatives. `first_order` is the matrix M of
#  r dY/dr = M Y, and `first_order_forcing` what remains when Y = 0 (a loading
#  that acts inside the layer).
#
#  Include it with
#
#      include(joinpath(pkgdir(MeanFieldHomogenization), "scripts", "common", "radial_first_order.jl"))
# =============================================================================

"""
    first_order_rhs(Y, unknowns, equations, r) -> (rhs, y)

`Y`: the state, expressions in the functions `unknowns` of `r` and their first
derivatives; `equations`: as many equilibrium equations, of the second order.
"""
function first_order_rhs(Y, unknowns, equations, r)
    d₁ = [diff(g, r) for g in unknowns]
    d₂ = [diff(g, r, 2) for g in unknowns]
    y = [symbols("y$i", real = true) for i in eachindex(Y)]
    nu = length(unknowns)
    from_law = solve([Y[nu + i] - y[nu + i] for i in 1:nu], d₁)        # r g′ from the traction
    from_equilibrium = solve(equations, d₂)                             # g″ from equilibrium
    rhs = [r * diff(Yᵢ, r) for Yᵢ in Y]
    rhs = [subs(e, [d₂[i] => from_equilibrium[d₂[i]] for i in 1:nu]...) for e in rhs]
    rhs = [subs(e, [d₁[i] => from_law[d₁[i]] for i in 1:nu]...) for e in rhs]
    rhs = [subs(e, [unknowns[i] => y[i] for i in 1:nu]...) for e in rhs]
    return [expand(simplify(e)) for e in rhs], y
end

"The matrix `M` of `r dY/dr = M Y`."
function first_order(Y, unknowns, equations, r)
    rhs, y = first_order_rhs(Y, unknowns, equations, r)
    return [simplify(diff(e, yⱼ)) for e in rhs, yⱼ in y]
end

"The second member of `r dY/dr = M Y + F`: the right-hand side at `Y = 0`."
function first_order_forcing(Y, unknowns, equations, r)
    rhs, y = first_order_rhs(Y, unknowns, equations, r)
    return [simplify(subs(e, [yⱼ => 0 for yⱼ in y]...)) for e in rhs]
end

5. A layer graded as a power of the radius ​

The matrices hold the moduli at the radius : they are those of a graded layer. When the moduli follow a power of the radius,    and   , the antiplane problem is an Euler equation, which is integrated in closed form:

julia
β = symbols("beta", real = true)
power = (p => p₀ * r^β, m => m₀ * r^β)
antiplane_equation = simplify(subs(divergence(stress(φ * cos(θ) * 𝐞ᶻ), Cyl) ⋅ 𝐞ᶻ / cos(θ), power...).doit() * r^(2 - β) / p₀)

   

julia
solution = dsolve(antiplane_equation, φ)

  

The exponents are the roots of    . They are the eigenvalues of the matrix of the reference moduli, being subtracted from the diagonal of its traction row (The radial problem, section 4):

k_c, k_s, b, R, k_m = 8.0, 0.4, 2.5, 1.6, 1.3
function closed_form(b, R)
    e = ((-b + sqrt(b^2 + 4)) / 2, (-b - sqrt(b^2 + 4)) / 2)             # s (s + β) = 1
    flux(s, r) = k_s * r^b * s * r^(s - 1)
    S = [
        1 -1 -1 0
        k_c -flux(e[1], 1) -flux(e[2], 1) 0
        0 R^e[1] R^e[2] -1 / R
        0 flux(e[1], R) flux(e[2], R) k_m / R^2
    ]
    return -2k_m * (S \ [0, 0, R, k_m])[4] / R^2
end

6. A wound coating ​

A fiber in a coating whose stiffness along the radius differs from that in the tangent plane, in the Mori-Tanaka scheme. With isotropic moduli written as a radial field, the isotropic coating is recovered:

julia
C₀, C₁, C₂ = iso_stiffness(10.0, 6.0), iso_stiffness(40.0, 20.0), iso_stiffness(4.0, 3.0)
function estimate(coating)
    rve = RVE()
    add_phase!(rve, :M, Ellipsoid(1.0), Dict(:C => C₀); fraction = :rest)
    add_phase!(rve, :I, LayeredCylinder((0.6, 1.0), (C₁, coating)), Dict(:C => C₁); fraction = 0.3)
    return ti_constants(best_fit_ti(homogenize(rve, MoriTanaka(), :C), (0.0, 0.0, 1.0)))
end
