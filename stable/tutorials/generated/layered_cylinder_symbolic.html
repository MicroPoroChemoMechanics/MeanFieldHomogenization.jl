The theory page Layered cylinder states the four radial problems of a coated fiber and the relations that carry their solution from one layer to the next. This page derives each of them with TensND's symbolic differential operators, then checks the package against the result.

A LayeredCylinder is an infinite fiber of axis made of coaxial layers, each transversely isotropic about . Under a remote uniform strain the displacement of each layer is a combination of a few elementary fields, the modes; an interface relates the modes of the two layers it separates. Three things are derived here: the modes, the conditions at an interface, and the order in which the moduli must be multiplied when they are operators that do not commute (aging viscoelasticity).

Writing the axis as loses nothing: a fiber of any other axis is the same problem in a frame whose third vector is , which the package sets with the axis keyword (Layered inclusions).

function traction_jump(u)

4. From one layer to the next ​

In a layer the amplitudes give the state at any radius (section 2), and the state at one radius gives the amplitudes back. Carrying a state across a layer is therefore a product of two matrices. For the antiplane problem, with the state :

julia
M(ρ) = [ρ 1 / ρ; p -p / ρ^2]                 # (A, B) ↦ (w, σ_rz) at radius ρ
r₁, r₂ = symbols("r_1 r_2", positive = true)
transfer = simplify.(M(r₂) * inv(M(r₁)))

This is the transfer matrix of a layer, in the sense of Hervé and Zaoui (1995): with the jump of the interface in between, the product of such matrices from the core to the matrix gives the state everywhere per unit core amplitude, and the remote condition fixes that amplitude. The package composes the same two maps, without forming the matrix:

julia
A₀, B₀ = LC._pot_amplitudes(r₁, p, w₀, U₀)
@assert all(iszero, simplify.(collect(LC._pot_state(r₂, p, A₀, B₀)) .- transfer * [w₀, U₀]))

The closed forms of the composite-cylinder model follow. A fiber of radius and moduli coated up to the radius 1 by a matrix answers an in-plane dilatation and an antiplane shear as a homogeneous fiber of moduli (Hashin and Rosen, 1964)

julia
k₁, p₁, k₂, m₂, p₂, a₁ = symbols("k_1 p_1 k_2 m_2 p_2 a", positive = true)
coating = ti_from_constants(k₂ + m₂, k₂ - m₂, l, n, p₂, (Sym(0), Sym(0), Sym(1)))
fiber = ti_from_constants(k₁ + m, k₁ - m, l, n, p₁, (Sym(0), Sym(0), Sym(1)))
sol = LC._elastic_solution(LayeredCylinder((a₁, Sym(1)), (fiber, coating)), coating)
u_R, σ_R = sol.dilatation.outside[2]
k_eff = factor(simplify(σ_R / (2u_R)))

julia
w_R, τ_R = sol.antiplane.outside[2]
p_eff = factor(simplify(τ_R / w_R))

julia

5. Moduli that do not commute ​

In aging linear viscoelasticity a modulus is a Volterra operator: the stress history is   , and two operators commute only in special cases (non-aging laws on a uniform time grid). The amplitudes become histories, and every product above must be read in a definite order. The rule is the one the mechanics gives: a modulus acts on the left of the strain it multiplies.

The transverse shear is the delicate case, because the shapes of its modes depend on the moduli. With non-commuting symbols, the strain of a mode   ,    and its equilibrium read

julia
K, Mo, α, β = symbols("K M alpha beta", commutative = false)
function shear_equilibrium(αe, βe, q)
    err = q * αe                              # ε_rr / r^(s−1)
    ett = αe + 2βe                            # ε_θθ / r^(s−1)
    g = -2αe + (q - 1) * βe                   # 2 ε_rθ / r^(s−1)
    srr = (K + Mo) * err + (K - Mo) * ett     # the moduli on the left
    stt = (K - Mo) * err + (K + Mo) * ett
    srt = Mo * g
    return expand((q - 1) * srr + 2srt + srr - stt), expand((q - 1) * srt - 2stt + 2srt)
end

(8*K*alpha + 4*K*beta + 4*M*alpha - 4*M*beta, -8*K*alpha - 4*K*beta - 4*M*alpha + 4*M*beta)
