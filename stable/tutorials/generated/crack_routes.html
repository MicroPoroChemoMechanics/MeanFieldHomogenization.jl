Every tensor on this page is in that normalization; the Conventions give the factor   that separates it from papers normalizing by .

The identity of §3 joins two independent computations of a crack, and this page runs both, first in an isotropic matrix where everything is a closed form, then in matrices drawn at random, to show that they meet.

  • From the crack plane. cod_tensor integrates the reduced kernel of the Green operator along the crack normal and around the crack front (Kanaun and Levin, 2009; Barthélémy, 2026): it returns , and follows from the identity (compliance_from_cod).

  • From a flattened ellipsoid. The crack is the limit of the ellipsoid of semi-axes as   (Barthélémy, 2009). The first-order term of its Hill tensor in gives by a computation on blocks of a matrix, and follows from the identity read the other way (cod_from_compliance).

function H_from_first_order(P₁, C, ℬ)
    Q₁ = -mandel(C) * P₁ * mandel(C)
    Y = mandel(from_mandel(Q₁, canonical), ℬ)
    H = zeros(eltype(Y), 6, 6)
    H[3:5, 3:5] = inv(Y[3:5, 3:5])
    return from_mandel(H, ℬ)
end

In random anisotropic matrices ​

Each matrix below is a random positive definite stiffness, fully anisotropic (21 independent constants), and each crack has a random orientation, both drawn by TensND (rand(rng, Tens{4, 3}; definite = true), random_rotation(rng)). is now the derivative, by ForwardDiff, of the Hill tensor computed by the nested cubature, taken at two small flatnesses and and combined so that its own first-order term cancels:    .

julia
function P₁_by_forwarddiff(a, b, R, C; ρ₀ = 1.0e-5)
    P(ρ) = mandel(hill_tensor(Ellipsoid(a, b, ρ * b, R), C; method = :nestedquadgk, tol...), canonical)
    P′(ρ) = ForwardDiff.derivative(P, ρ)
    return 2 * P′(ρ₀ / 2) - P′(ρ₀)
end

An analytic anchor in an anisotropic matrix ​

Neither route above is a closed form in an anisotropic matrix. One exists when the matrix is the image of an isotropic one by a linear map   ,       (elliptic orthotropy). The crack of radii maps to a crack of radii and normal in the isotropic matrix, whose is a closed form, and (Barthélémy, 2026) gives, in the normalization of the package,

julia
function transformed_crack(P, a, b, ℓ, m, n)
    g, h = P \ ℓ, P \ m
    area = norm(cross(g, h))
    s₊ = sqrt(a^2 * norm(g)^2 + b^2 * norm(h)^2 + 2a * b * area)
    s₋ = sqrt(a^2 * norm(g)^2 + b^2 * norm(h)^2 - 2a * b * area)
    ã, b̃ = (s₊ + s₋) / 2, (s₊ - s₋) / 2
    ñ = normalize(transpose(P) * n)
    w_ℓ = (a^2 * norm(g)^2 - b̃^2) * g + b^2 * dot(g, h) * h
    w_m = a^2 * dot(g, h) * g + (b^2 * norm(h)^2 - b̃^2) * h
    ℓ̃ = normalize(norm(w_ℓ) ≥ norm(w_m) ? w_ℓ : w_m)
    return ã, b̃, hcat(ℓ̃, cross(ñ, ℓ̃), ñ)
end

Pmap = [1.3 0.2 -0.1; 0.15 0.8 0.25; -0.05 0.3 1.1]
PP = mandel(Tens(Pmap) ⊠ˢ Tens(Pmap))
C̃ = TensISO{3}(3 * 20.0, 2 * 9.0)
C_EO = from_mandel(PP * mandel(C̃) * transpose(PP), canonical)
a, b = 1.0, 0.45
R = Matrix(random_rotation(Xoshiro(2)))
ℓ, m, n = eachcol(R)
ã, b̃, R̃ = transformed_crack(Pmap, a, b, ℓ, m, n)
B̃ = canonical_components(cod_tensor(EllipticCrack(ã, b̃, R̃), C̃))
B_rule = (b̃ / b) / norm(transpose(Pmap) * n) * (transpose(Pmap) \ B̃ / Pmap)
crack = EllipticCrack(a, b, R)
H_EO = H_from_first_order(P₁_by_forwarddiff(a, b, R, C_EO), C_EO, crack_basis(crack))
for (label, B) in (
        ("crack plane, nested cubature", cod_tensor(crack, C_EO; method = :nestedquadgk, tol...)),
        ("crack plane, residues", cod_tensor(crack, C_EO; method = :residues, tol...)),
        ("crack plane, DECUHR", cod_tensor(crack, C_EO; method = :decuhr, tol...)),
        ("flattened ellipsoid", cod_from_compliance(H_EO, crack)),
    )
    @printf "%-30s %.1e\n" label norm(canonical_components(B) - B_rule) / norm(B_rule)
end
